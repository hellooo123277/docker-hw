**Домашнее задание по Docker на 8 баллов**



**# Как запустить**

Выполните команду: `docker compose up -d --build`

Приложение будет доступно по адресу: http://localhost:8080



**# Настройки**

Приветствие задается в файле `compose.yaml` в переменной `GREETING`.

Хранилище (Redis) подключено через сервис `redis`.
